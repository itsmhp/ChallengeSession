1 · Spacing Scale — 4px Base Grid
Semua padding, margin, dan gap harus kelipatan 4px. Konsistensi ini memudahkan alignment dan membuat layout terasa "rapi" secara visual.
2 · Border Radius Tokens
Dari none (tabel/divider) sampai full (pill badge, toggle button). Konsisten di seluruh komponen ketiga dashboard.
3 · Shadow & Elevation — 4 Level
Level 0 = flat (tabel, divider). Level 1 = card default. Level 2 = dropdown/popover. Level 3 = modal/drawer. Hover card untuk lihat efek.
4 · Component States — 5 State Wajib
Setiap elemen interaktif (button, input, row tabel, link) harus punya 5 state ini. Ini yang membuat dashboard terasa responsif dan profesional.
Dark mode states: default bg = #1B3860, hover = #274E80, focus ring = 0 0 0 3px rgba(75,150,230,.3)
5 · Opacity Scale
Untuk overlay, disabled state, skeleton loader, hover background. Jangan gunakan nilai opacity ad-hoc — selalu ambil dari scale ini.
6 · Z-index Scale — Layer Hierarchy
Hierarki layer yang jelas agar modal, tooltip, dropdown, dan header tidak saling tabrakan antar komponen maupun antar dashboard.
7 · Transition Tokens
Durasi dan easing yang konsisten. Arahkan mouse ke setiap card untuk preview transisi masing-masing.
8 · Breakpoints & Grid System
6 breakpoint untuk layout responsif. Gunakan CSS Grid dengan auto-fit untuk KPI cards.
/* Responsive grid helpers */ .grid-2 { display:grid; grid-template-columns:repeat(2,1fr); gap:var(--space-4); } .grid-3 { display:grid; grid-template-columns:repeat(3,1fr); gap:var(--space-4); } .grid-4 { display:grid; grid-template-columns:repeat(4,1fr); gap:var(--space-4); } .kpi-grid { display:grid; grid-template-columns:repeat(auto-fit,minmax(200px,1fr)); gap:var(--space-4); } @media (max-width:768px) { .grid-3,.grid-4 { grid-template-columns:repeat(2,1fr); } } @media (max-width:480px) { .grid-2,.grid-3,.grid-4 { grid-template-columns:1fr; } }
